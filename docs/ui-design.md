# UI 設計規範：切角科幻風

Highway Thunder 2 所有畫面（標題、車庫、比賽 HUD、暫停、完賽、彈窗）共用的視覺語言。
新增或修改 UI 時照這份做；要破例，先改這份文件。

示意圖在 `docs/ui/`：`garage.jpg`、`setup.jpg`、`hud.jpg`、`tacho.jpg`、`tacho-redline.jpg`、`pause.jpg`、`finish.jpg`。
示意圖裡的數值只是示範；和本文不一致的地方以本文為準（見最後一節「示意圖與定案的差異」）。

---

## 1. 原則

1. **沒有圓角。** 轉角一律是斜切、直角或六角。`border-radius` 只能用在本來就是圓的東西上（轉速表的環）。
2. **斜，代表速度。** 按鈕是平行四邊形，分段條是斜切的小塊，大數字往右斜。
3. **車是主角的畫面不放面板。** 比賽 HUD 和車庫的資訊直接浮在畫面上，靠陰影或一圈放射狀暗影維持可讀性；面板只用在蓋在畫面上的選單（暫停、完賽、比賽設定抽屜、彈窗）。
4. **選中就整塊填滿。** 選中的項目整塊填主色、文字變白；不是只換邊框顏色。
5. **英文小標，中文內容。** 區塊用大寫英文小標（`SELECT CLASS`、`TIME`）標示，按鈕和內容用中文。
6. **畫面上不放說明文字。** 解釋性的文字（某個選項是什麼意思、怎麼用鍵盤操作、還不能選的原因）收進一個「?」圖示（`.help`）或元件本身的 `data-tip`，滑鼠移上去或用鍵盤聚焦時才顯示；提示框可以多行，一行一項。比賽中沒辦法 hover，所以 HUD 上必要的提示（例如 `R` 回到賽道）照舊顯示。
7. **全部可以只用鍵盤操作。** 每個選單都有一個游標：方向鍵移動（選中的項目整塊填色，跟滑鼠 hover 同步）、Enter 確認、Esc 返回或關閉。鍵帽標在它控制的元件旁邊；游標移到某一列時，那一列的「?」說明自動打開。用 Tab 聚焦的按鈕要看得出來（白色外框；切角的元件因為會裁掉外框，改成整塊填主色）。

## 2. 設計變數（tokens）

示意圖以 1920×1005 繪製，下表的 px 都以這個尺寸為準。實作時一律換成 `vw`，換算方式是 px ÷ 19.2（例：18px → 0.94vw）。

### 顏色

| 變數 | 值 | 用途 |
|---|---|---|
| `--accent` | 玩家所選車的顏色（預設 `#ff3b30`），由 `Hud.setAccent` 設定 | 選中狀態、主按鈕、角框、小標前的短線、六角框 |
| `--danger` | `#ff3b30`（固定，不隨車色變） | 轉速紅區 |
| `--nitro` | `#2fd6ff` | 氮氣 |
| `--glass` | `rgba(8, 12, 22, 0.66)` | 面板底色（加 `backdrop-filter: blur(8px)`） |
| `--line` | `rgba(255, 255, 255, 0.16)` | 面板外框、分隔線 |
| 文字：主要 | `#eef3fb` | 內容、數字 |
| 文字：次要 | `#c9d3e6` | 未選中的按鈕文字 |
| 文字：小標 | `rgba(255, 255, 255, 0.5)` | 英文小標 |
| 未亮分段 | `rgba(255, 255, 255, 0.10)` | 分段條沒點亮的格子 |

### 字體

| 角色 | 字體 | 樣式 |
|---|---|---|
| 標題、大按鈕 | `"Microsoft JhengHei"`（英文用 `"Segoe UI"`） | `italic 900`，字距 2–8px |
| 數字 | `"Bahnschrift"`（備用 `"Segoe UI"`） | `600–700`、`tabular-nums`；大數字加 `skewX(-8deg)` |
| 英文小標 | `"Bahnschrift"` | `600 12px`、大寫、字距 3px |
| 內文、按鈕 | `"Microsoft JhengHei"` | `700` |

Bahnschrift 是 Windows 10 以後內建的字體。上線前要附網頁字型檔（或換成授權允許內嵌的 DIN 類窄體字），不然 Mac 和手機會退回 Segoe UI 或系統字。

大數字的小數或單位部分縮成約 60%，顏色降到 0.6–0.75 不透明（例：`0:20`<small>`.225`</small>、`300`<small>`km/h`</small>）。

### 角度

| 用途 | 角度 |
|---|---|
| 一般按鈕（平行四邊形） | `skewX(-12deg)` |
| 主按鈕（開始比賽） | `skewX(-14deg)` |
| 烤漆色票 | `skewX(-18deg)` |
| 斜分隔線 | `skewX(-20deg)` |
| 轉速塊 | `skewX(-24deg)` |
| 分段條的格子、小標前短線 | `skewX(-30deg)` |
| 大數字 | `skewX(-8deg)` |

## 3. 形狀

### 切角 `.cut`
左上和右下兩個角斜切，其他兩角維持直角，所有面板、鍵帽都用這個形狀。切角大小 `--c` 依元件大小決定：

| 元件 | `--c` |
|---|---|
| 鍵帽 | 7px |
| 小按鈕（按鍵說明） | 10px |
| 一般面板、比賽設定卡 | 18px |
| 大面板（車輛數值、暫停） | 26px |
| 完賽面板 | 30px |

```css
.cut { clip-path: polygon(var(--c) 0, 100% 0, 100% calc(100% - var(--c)), calc(100% - var(--c)) 100%, 0 100%, 0 var(--c)); }
```

### 有框面板 `.panel`
`clip-path` 會把 `border` 一起切掉，所以邊框用兩層做：元素本身塗外框色，`::before` 往內縮 1px 塗玻璃底色，並沿用同一個 `clip-path`。

```css
.panel { position: relative; background: var(--line); }
.panel::before { content: ""; position: absolute; inset: 1px; background: var(--glass); clip-path: inherit; backdrop-filter: blur(8px); }
.panel > * { position: relative; }
```

### 角框 `.brk`
用主色畫的 L 形，2px 粗、22px 長，放在面板**沒有切角**的那兩個角（右上、左下），往外突出 6px。只用在每個畫面最主要的那塊面板上，一個畫面最多一組。

### 六角 `.hex`
`clip-path: polygon(25% 0, 75% 0, 100% 50%, 75% 100%, 25% 100%, 0 50%)`。兩層疊起來：外層塗主色，內層深色、各邊縮 3px，看起來就像 3px 的框。只用在**名次**和**檔位**上。

### 平行四邊形
外框用 `skewX` 傾斜，裡面的內容再用反方向的 `skewX` 轉正，讓文字不跟著歪。

## 4. 元件

### 小標 `.lbl`
英文大寫，12px，字距 3px，用小標文字色。放在區塊左上方時，前面加一條主色短線（26×4px，`skewX(-30deg)`）。

### 選項按鈕 `.opt`（車種、暫停選單、完賽按鈕）
- 平行四邊形，高 72–92px，左側有 4px 寬的邊條。
- **一般**：底色 `rgba(255,255,255,0.05)`（疊在面板上）或 `rgba(8,12,22,0.62)`（直接疊在畫面上），邊條 `rgba(255,255,255,0.18)`，文字用次要色。
- **選中**：整塊填主色，邊條變白，文字變白，外面加一圈主色光暈（`0 0 36px -6px`）。右端加一條 6px 寬的白色豎條，按鈕外再多一條主色斜條（參考 `garage.jpg` 的 01 超跑）。
- **滑鼠移過**：往右移 0.3vw，邊條換成主色。
- **編號**：每個選項前面加 `01`、`02`……（14px Bahnschrift，0.35 不透明）。

### 主按鈕 `.cta`（開始比賽）
- 主色平行四邊形（`skewX(-14deg)`），後面多一條錯開 (10px, 8px) 的主色外框線，不透明度 0.6。
- 字用 `italic 900`、字距 8px，後面接 `›››` 三個箭號，不透明度由淡到濃。
- 對應的鍵盤按鍵直接放進按鈕裡，例如 `ENTER`。

### 鍵帽 `.key`
淺色底（`#dfe6f3`）、深色字，`.cut` 切角 `--c: 7px`，字是 14px Bahnschrift。放在它控制的元件旁邊；不要另外做一整排按鍵說明。

### 分段條 `.seg`（車輛數值、氮氣）
- 數值條 20 格，氮氣 16 格；格子之間空 3–4px，每格 `skewX(-30deg)`。
- 點亮的格子填主色並發光，氮氣用 `--nitro`；沒亮的用「未亮分段」色。
- 數值條高 12px，氮氣高 8px。

### 烤漆色票
46×30px 的平行四邊形（`skewX(-18deg)`），斜線把主色和輔色分成兩半。選中的那個加 2px 白框，往外留 3px，並帶一點同色光暈。

### 浮動數字（HUD）
不加面板，靠 `text-shadow: 0 2px 10px rgba(0,0,0,.85), 0 0 2px rgba(0,0,0,.9)` 維持可讀性，搭配小標使用。

### 斜分隔線
同一排並列的項目之間，用 2px 寬、帶 `skewX(-20deg)` 的直線隔開。

### 遮罩 `.veil`（暫停、完賽）
`rgba(4,6,12,0.62)`，加 `backdrop-filter: blur(6px) saturate(0.7)`，上面再疊一層很淡的掃描線（每 4px 一條 1px、白色 0.025 不透明）。

## 5. 畫面

### 車庫（`garage.jpg`）
車是主角，資訊全部避開車。車庫鏡頭會在車前方左右擺動 ±20°，擺到側面時車最寬：超跑側面大約佔畫面寬度 19.5%–76%、高度 45%–84%。所有元件都放在這個範圍外：上方 40% 的天空、左右兩側各約兩成寬、底部一條。資訊不放面板，直接浮在畫面上；畫面左右兩側另外加一層淡淡的暗邊，讓浮字在城市燈光上也讀得清楚。

| 區 | 內容 |
|---|---|
| 左上 | 品牌標誌；下方一條主色漸層線，左端有一段主色粗短條 |
| 上方正中 | 車型英文（`SUPERCAR`）和 `01 / 03`、大字車名（84px）、主色漸層短線、三個數值橫排（圖示＋小標、40px 斜體數字、分段條，中間用斜分隔線隔開）；底下墊一圈放射狀暗影，不是面板 |
| 左側（車的左邊） | `SELECT CLASS` + `↑` `↓` 鍵帽，車種選項按鈕直排（高 63px，車名小字，因為上方已經有大字車名） |
| 車底下正中 | `PAINT` ＋ `←` 烤漆色票 `→`：鍵帽就放在它控制的色票兩邊 |
| 右下 | 比賽設定摘要：三行浮字（對手、難度、天氣），標頭寫 `RACE SETUP` 和 `E` 鍵帽 `EDIT ▸`；整塊可點，滑鼠移上去時加主色細框和淡色底，點了開比賽設定抽屜。正下方是主按鈕「開始比賽」 |
| 右上角 | `H` 鍵帽＋浮字「操作說明」（跟比賽中的 `R` 回到賽道同一種呈現，沒有方塊），點了或按 H 打開按鍵說明 |

按鍵：↑↓ 換車種，←→ 換烤漆，E 開比賽設定，H 開操作說明，Enter 開始，Esc 關掉抽屜或彈窗。

**標題畫面**沿用同一套元件：左半是大標題和主按鈕，右半是車。按下開始後車往左滑到中央，車庫的元件淡入。

### 比賽 HUD（`hud.jpg`）
| 位置 | 元件 |
|---|---|
| 左上 | 計時：`TIME` 小標 + 64px 浮動數字 |
| 上方中央 | 進度條：900px 寬的 2px 細線，每 20% 一個斜刻度；已跑過的部分是主色漸層。對手是車色菱形（12px，轉 45°），自己是上方的白色倒三角，終點放旗子圖示，剩餘距離寫在右下方 |
| 右上 | 名次：六角框裡放 72px 數字，旁邊是 `/6` 和 `POSITION` |
| 右下 | 轉速表（見下） |
| 左下 | `R` 鍵帽 +「回到賽道」，**只有需要時才出現**（見下） |
| 中下 | 後方車輛警示：主色倒三角 + 距離，沒有面板 |
| 角落 | AI、靜音標籤：`.cut` 小標籤 |

**不顯示**：近距超車（near miss）的連擊計數。這個次數只在完賽畫面出現。

**R 提示的出現條件**（比賽進行中，任一條成立）：
- 車速低於 5 km/h 持續 3 秒；
- 車身翻覆或側翻（車頂朝向的 y < 0.5）持續 1 秒。

條件不再成立時，提示淡出。重置冷卻中仍然照規則顯示，但降低不透明度。兩個秒數放進調整面板，方便調。

### 轉速表（`tacho.jpg`、`tacho-redline.jpg`）
沒有錶盤面板的「斜切分段環」，整體約 323px 寬，放在右下角。

- **幾何**：跟現在的 `hud.ts` 相同。0–8（×1000 rpm）分佈在 240°，從 150° 開始，7 以上是紅區。
- **轉速環**：32 個斜切的梯形塊，越接近紅線越粗。每 1000 轉之間的空隙比較寬，讓刻度好算。點亮的塊是 `#c9d3e3`；**目前轉速那一格**比其他格長 5 單位，純白並發光，取代原本的指針。沒亮的塊幾乎透明，只留細框。
- **刻度數字**：0–8 用斜體 Bahnschrift，紅區的數字用 `--danger`。
- **中央**：速度 112px 浮動數字，下方是 `KM/H` 小標。
- **檔位**：放在環下方缺口裡的六角框。
- **氮氣**：環外側左下方（0–2.5 那段）放 10 格青色分段，由下往上填，旁邊標 `N2O`。
- **暗影**：錶後方墊一圈放射狀暗影（不是面板），讓沒亮的塊在被車燈照亮的路面上也看得清楚。
- **紅區狀態**：紅區的塊點亮並發光，暗影轉成暗紅，檔位六角框變成實心紅。**不顯示換檔提示**，因為遊戲是自動變速。

### 暫停（Esc，`pause.jpg`）
遮罩上放一塊 560px 寬的 `.panel` 加 `.brk`，內容依序是 `PAUSED` 小標、大字「暫停」、目前的時間／名次／剩餘距離（用分隔線上下夾住）、選項按鈕「繼續（ESC 鍵帽）」和「回車庫」。游標一開始在「繼續」，↑↓ 移動，Enter 確認；Esc 不管游標在哪都直接繼續。

### 完賽（`finish.jpg`）
遮罩上放一塊 900px 寬的 `.panel` 加 `.brk`：
- 頂部是 `RACE COMPLETE` 小標和大字「抵達終點！」。
- 左邊是 196px 的名次六角框。
- 右邊是 `FINISH TIME` 小標和 92px 的完賽時間；時間加主色光暈，避免在亮背景上糊掉。破紀錄時小標旁加主色的 `NEW BEST`。
- 沒有對手時（只有自己）不顯示名次六角框，時間佔滿整列。
- 下方一排，用斜分隔線分開：近距超車次數、極速、距離。
- 最下面兩個按鈕並排：「再一場」和「回車庫（ESC 鍵帽）」。游標一開始在「再一場」，←→（或 ↑↓）移動，Enter 確認；Esc 直接回車庫。

### 比賽設定抽屜（`setup.jpg`）
從右側滑出的抽屜（614px 寬，`.panel` 加 `.brk`），沒有遮罩。抽屜打開時，車往左滑讓出位置，改設定時還看得到車；車庫自己的元件淡出，只留品牌標誌。

- **標頭**：`RACE SETUP` 小標、「比賽設定」、一個「?」（鍵盤操作說明）、右上角 `ESC 收起`。
- **對手**：
  - 數量：0–5 一排直接點（數字鍵也能直接設定）。
  - 車種：二級選單，三個模式「全部隨機」「全部同我的車」「自由指定」，右邊一個「?」說明三者的差別。
    - 全部隨機：每場比賽開始時重新抽。
    - 全部同我的車：跟著玩家目前的車，換車時對手也一起換。
    - 自由指定：才展開「對手 × 車種」表格。每台對手一列，左邊是它名次顏色的編號方塊；每種車一欄，車名只寫在欄位標題，玩家自己的車那欄標上 `YOU`。
  - 標題右側是對手摘要：隨機 ×5，或各車種的數量。
- **難度**：四個平行四邊形按鈕；標題右側一個「?」，每一級用一句話描述對手的表現（不寫數字），文字來自 `DIFFICULTIES` 的 `hint`。
- **天氣**：還不能選的天氣用斜紋底並調淡，滑鼠移上去顯示「即將推出」。
- **底部**：主按鈕「開始比賽」，固定在抽屜底部。抽屜一律佔滿畫面高度，內容變短時空白留在內容和按鈕之間，所以改設定不會讓按鈕移動。
- **鍵盤**：↑↓ 在「數量、車種模式、各對手（自由指定時）、難度、天氣」之間移動，目前那一列有淡色底和左側主色條，有「?」的列會自動打開說明；←→ 調整那一列的值（天氣只在已開放的之間切換）；0–5 設定數量；Enter 開始；Esc 收起。

**螢幕高度不夠時**，依序處理（縮放比例以最高的內容來算，也就是自由指定加 5 台對手，所以切換設定時抽屜的大小不變）：
1. 整個抽屜等比例縮小（`zoom`），保證放得下，最小縮到 75%。
2. 縮到 75% 還放不下，切換成緊湊版：各列和間距變矮。
3. 還是放不下時，中間內容可以捲動，「開始比賽」固定在底部；用鍵盤移到看不到的列時會自動捲過去。

### 按鍵說明彈窗
外框是 `.panel` 加 `.brk`，背後加遮罩；關閉鈕用切角小按鈕，不要做成圓形。

### 倒數與提示訊息
- **倒數**：數字沿用現在的大小，換成 Bahnschrift 斜體，保留主色光暈。
- **提示訊息（toast）**：用切角面板，左側加一條主色邊條。

## 6. 動態

- 比賽中的 HUD 動畫（數字跳動、紅區發光、提示淡入淡出）一律跟著比賽時間步進 `play` 走，暫停時停止。
- 選單（車庫、暫停、完賽、彈窗）的 hover 和切換用 CSS transition，時間 0.15–0.3s。
- 面板出現時從斜下方滑入 8–12px 並淡入，不要放大縮小。

## 7. 不要做

- 不要用圓角（`border-radius`）；轉速環本身是圓的，不算在內。
- 不要在比賽 HUD 和車庫上放玻璃面板，也不要讓車庫的元件擋到擺動中的車（見車庫的範圍）。
- 不要做整排的按鍵說明；鍵帽放在它控制的元件旁邊。
- 選中狀態不要只換邊框顏色。
- 同一個畫面不要用超過一組角框。
- 不要另外發明新的形狀；需要新元件時，用上面的形狀組合出來。
